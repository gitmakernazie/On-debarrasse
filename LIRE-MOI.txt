ON DÉBARRASSE QUÉBEC — site complet (nouvelle identité de marque)

Contenu : index.html (accueil), soumission.html, contact.html, confirmation.html,
politique-confidentialite.html, gestion.html (tableau de bord privé), suivi.js (suivi Google Ads,
éteint tant qu'il n'est pas configuré), vercel.json, les icônes (favicon*.png, apple-touch-icon.png)
et les images (.webp).

Mise en ligne (GitHub -> Vercel) :
1. Dézippez ce dossier (clic droit > Extraire tout).
2. Sur GitHub, ouvrez le dépôt On-debarrasse > Add file > Upload files.
3. Glissez TOUS les fichiers du dossier (pas le dossier lui-même) et confirmez (Commit).
   Les fichiers du même nom sont remplacés. Vercel publie automatiquement.

Important :
- Domaine: bazarvert.ca (DNS Cloudflare + Vercel). Courriel: info@ondebarrassequebec.ca (Cloudflare Email Routing). L ancien domaine ondebarrasse.ca peut etre redirige dans Vercel.
  (le nouveau domaine n'est pas connu).
- Les photos des cartes de services (s-*.webp) sont des images temporaires trouvées sur le web.
